企业采用 AI，最终要回答的是：**效果能否验证，部署能否自主掌握，成果能否进入日常工作。**

我的工作围绕这些问题展开。自 2024 年加入 CET，主导 **9 个 AI 项目从 0 到 1**，从模型训练推进到业务交付。

## 技术判断，要经得起业务检验

### 更小的模型，能否承担复杂业务？

在企业台账查询场景中，我主导私有化 Agent 的后训练体系，覆盖数据生产、监督微调、强化学习、奖励设计与评估。

**在同口径台账工具任务的模型裁判（Judge）评估中：**

| 模型 | 参数量 | 正确率 |
| :--- | ---: | ---: |
| 我主导训练的专用模型 | 20 亿（2B） | **86%** |
| 外部对照模型 | 350 亿（35B） | 63% |

这一结果限定在该业务任务。它为企业私有化部署提供了一个经过任务评估的小模型方案；项目中的数据治理、训练与诊断方法，也成为后续 Agent 工作的基础。

### 算法成果，如何走到使用者手里？

我主导 CADDrawer 智能绘图引擎，把结构化数据转成经过规则校验与空间布局的 DWG 图纸，通过钉钉工作台交付设计院使用。

**小时级手工绘图 → 分钟级生成，人力节省 80%+。**

从算法到文件格式、业务入口和用户交付，都是这项工作的组成部分。
